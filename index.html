Sobre

Sou Gustavo Santos, engenheiro de software focado em sistemas de gestão, APIs e IA aplicada a processos de negócio. Trabalho de ponta a ponta: entendo a operação, modelo os dados, desenho a arquitetura, construo API e interface, faço o deploy e acompanho a adoção pela equipe.

Minha base é C#/.NET para sistemas web e APIs, e Python para automação, dados e agentes de IA. Comecei transformando rotinas administrativas manuais em ferramentas automatizadas, e esse continua sendo o meu foco: software que resolve problemas reais de operação, com segurança, testes e documentação desde o primeiro dia.

Atualmente desenvolvo os sistemas internos de uma empresa de home care (gestão, captação de profissionais com IA e central de atendimento) e curso Engenharia de Software.

Sistema HomeCare

Visão Geral

Desafio. Centralizar a operação de uma empresa de home care (pacientes, profissionais, ocorrências, evoluções clínicas, relatórios e financeiro) num único sistema, com cada setor acessando apenas o que lhe cabe.

Solução. Projetei e construí o sistema de ponta a ponta: API em ASP.NET Core 8 organizada por features, front-end em React e deploy em Docker com HTTPS via Caddy.

Decisões técnicas. Controle de acesso por perfil e setor, com entrada apenas por convite de uso único; segredos fora do repositório e banco isolado da rede; fotos de prontuário em armazenamento compatível com S3; e migração para Clean Architecture planejada em fases, cada uma validada por testes automatizados.

Captação com IA

Visão Geral

Desafio. Acelerar a captação de profissionais de saúde sem abrir mão da confiabilidade dos dados nem da conformidade com a LGPD.

Solução. Pipeline multiagente: a partir do nome do profissional, agentes verificam o registro no conselho de classe, mapeiam a presença profissional pública e os contatos publicados, e consolidam tudo em PostgreSQL, exibido num painel web.

Decisões técnicas. Agentes independentes executados em paralelo; toda informação carrega a sua fonte; consulta restrita a fontes profissionais públicas, com lista de bloqueio; tool calling sobre API compatível com OpenAI e provedores de busca intercambiáveis, evitando dependência de um único fornecedor.

Central WhatsApp

Visão Geral

Desafio. Unificar o atendimento via WhatsApp da empresa, antes espalhado entre aparelhos, numa central com múltiplos atendentes, histórico e distribuição de conversas.

Solução. Integração entre Evolution API e Chatwoot via webhook, com gateway de LLM para respostas assistidas, orquestrada com Docker Compose sobre PostgreSQL (pgvector) e Redis.

Decisões técnicas. Ambientes local e de produção separados; serviços compilados a partir do código-fonte com customizações próprias; banco e cache sem exposição à rede; configuração fail-fast, que impede a subida sem os segredos obrigatórios; e manual e treinamento da equipe como parte da entrega.

Automação com IA

Visão Geral

Desafio. Eliminar tarefas repetitivas que consumiam o tempo das equipes em processos administrativos e operacionais.

Solução. Fluxos automatizados que recebem demandas, interpretam o conteúdo com LLMs, consultam sistemas e executam a ação, devolvendo às equipes o tempo antes gasto em trabalho manual.

Decisões técnicas. N8N para orquestração dos fluxos e frameworks de agentes (Agno, LangChain, Semantic Kernel) escolhidos conforme a complexidade de cada processo.
