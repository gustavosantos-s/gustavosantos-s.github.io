Quem sou eu no mercado?

Muito prazer, sou o Gustavo. Minha jornada na tecnologia começou cedo, modificando jogos e montando ambientes, mas foi no meu primeiro emprego como aprendiz administrativo que a ficha caiu. Para me destacar na equipe e ganhar agilidade, comecei a automatizar tarefas repetitivas do setor usando ferramentas que encontrava. Logo percebi uma barreira: a internet não tinha softwares prontos para resolver todos os nossos problemas. Quando alguém em um fórum me disse "você vai ter que programar o seu próprio", aceitei o desafio.

Hoje, sou estudante de Engenharia de Software com foco em Inteligência Artificial. Utilizo Python para criar automações inteligentes e tratar dados de ponta a ponta, e venho me aprofundando diariamente no ecossistema C# (.NET) para construir arquiteturas Web robustas. Mais do que apertar teclas, o que me fascina na programação é a empolgação imensa de tirar uma ideia do papel e construir uma solução real do zero. Eu construo as ferramentas que não encontro prontas.

Hoje desenvolvo os sistemas internos de uma empresa de home care: o sistema de gestão em ASP.NET Core + React, agentes de IA que ajudam o RH a encontrar profissionais e a central que reúne todo o atendimento via WhatsApp. Em cada um fiz o caminho inteiro: modelar o banco, escrever a API, construir as telas, subir com Docker e treinar a equipe.

Sistema HomeCare

Visão Geral

Sistema de gestão completo para uma empresa de home care: pacientes, profissionais, quadro de ocorrências, evoluções clínicas, relatórios em PDF e financeiro. Cada pessoa enxerga só o que o seu setor precisa, com perfis de administrador, gestor, operador e profissional externo, e todo acesso nasce de um convite de uso único.

A API em ASP.NET Core 8 é organizada por features, com EF Core sobre PostgreSQL, fotos de prontuário num armazenamento compatível com S3 (MinIO) e segredos fora do repositório. Com o sistema crescendo, planejei a migração para Clean Architecture em fases, cada uma terminando com a suíte de testes verde.

Captação com IA

Visão Geral

Sistema de IA para o RH: a partir do nome completo de um profissional de saúde, agentes buscam o registro no conselho de classe, a presença profissional pública e os contatos profissionais publicados, sempre informando a fonte de cada dado.

Um orquestrador roda os agentes de registro e presença em paralelo; o agente de contato usa o que eles encontraram e um último agente consolida tudo no PostgreSQL, exibido num painel web. Os agentes usam tool calling com busca web e leitura de páginas, respeitam uma lista de bloqueio e só consultam fontes profissionais públicas, em conformidade com a LGPD.

Central WhatsApp

Visão Geral

Central única de atendimento via WhatsApp: a Evolution API conecta os números da empresa e entrega cada mensagem por webhook ao Chatwoot, onde a equipe atende em conjunto, com histórico, etiquetas e distribuição de conversas. Um gateway de LLM apoia as respostas.

Tudo é orquestrado com Docker Compose, com ambientes local e de produção separados, PostgreSQL com pgvector e Redis. Banco e cache só são acessíveis pela própria máquina, e sem as senhas no .env o sistema se recusa a subir. Também escrevi o manual e o termo de treinamento da equipe.
